# Drone X4 — Reference-Matched UI Template

A responsive drone product feature page styled closely to the supplied monochrome reference:
- Large editorial hero with 4K badge and grayscale drone photography
- Dark five-column smart-features strip
- Two side-by-side product detail panels
- What's-in-the-box accessory lineup
- Dark trust/service footer

## Run
Extract the folder and open `index.html` in a browser. No build step or package installation is needed.

## Customize
Edit copy and image URLs in `index.html`; change layout, typography and grayscale styling in `styles.css`.
The `assets/` directory contains the original design reference image when it was available.
Sample remote images and Google Fonts require an internet connection.
